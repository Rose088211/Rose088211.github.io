为（kernel 5.10-6.x）GKI2.0设备支持的安装方式
KernelSU 安装方式选择（二选一）
│
├─ GKI 模式（通用内核镜像）
│   ├─ 文件：android14-6.1.141_2025-07-boot-gz.img.gz
│   ├─ 刷入方式：电脑 + fastboot 命令（如 fastboot flash boot）
│   ├─ 原理：用 KernelSU 提供的通用内核完整替换手机原厂内核
│   ├─ 优点
│   │   ├─ 通用性强，无需依赖官方固件
│   │   └─ 对三星 KNOX 等特殊设备可能是唯一可用方案
│   ├─ 缺点
│   │   ├─ 不易回退（替换了整个内核）
│   │   └─ 升级麻烦（需重新下载镜像并用电脑刷入）
│   └─ 官方状态：KernelSU v3.0 后已停止对 GKI 镜像模式的官方支持
│
├─ LKM 模式（可加载内核模块）★ 官方推荐
│   ├─ 文件：AnyKernel3-android14-6.1.141_2025-07.zip
│   ├─ 刷入方式
│   │   ├─ 第三方 Recovery（如 TWRP）
│   │   └─ 已 Root 设备可用 KernelFlasher 等 App 刷写
│   ├─ 原理：以动态模块形式加载到原厂内核，不替换内核本身
│   ├─ 优点
│   │   ├─ 风险低：保留原厂内核，出问题易恢复
│   │   ├─ 升级方便：可在 KernelSU 管理器 App 内直接升级
│   │   ├─ OTA 友好：系统更新后通常无需重刷
│   │   └─ 可临时卸载 Root（甚至无需重启）
│   ├─ 缺点
│   │   └─ 刷入前需从官方固件提取原厂 boot 镜像进行修补（流程略繁琐）
│   └─ 适用建议：绝大多数普通用户的优先选择


│
└─ 总结选择建议
    └─ 除非设备特殊（如三星 KNOX 开启导致 LKM 无效），否则请优先使用 LKM 模式（AnyKernel3.zip）
