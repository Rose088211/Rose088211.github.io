Android APP 漏洞
1. APK 获取与基础信息
获取 APK：设备提取、商店下载、第三方渠道、CI 产物。

基础信息：

包名、版本号、versionCode、minSdk/targetSdk。

签名、证书、是否 debug 签名。

权限清单、exported 组件、深链、网络配置。

工具：adb、aapt2、apksigner、apktool、jadx、MobSF。

2. 静态黑盒 / 客户端分析
不接触源码，只看 APK 产物：

AndroidManifest.xml：

debuggable、allowBackup、usesCleartextTraffic。

导出 Activity/Service/Receiver/Provider。

深链、Intent Filter、权限保护。

资源与字符串：

硬编码 API、密钥、Token、测试账号、内网地址。

Firebase、AWS、地图、支付、推送 SDK key。

代码：

反编译看关键逻辑、加密、签名、风控、Root 检测。

搜索 http://、https://、api、secret、key、password。

工具：jadx、apktool、MobSF、APKLeaks、gitleaks、semgrep。

3. 安装运行与设备环境
真机 / 模拟器，不同 Android 版本。

Root / 非 Root，多用户、工作资料。

测试：

安装、启动、升级、降级、卸载重装。

多进程、后台、锁屏、分屏、旋转。

低内存、断网、弱网、代理、飞行模式。

观察日志：adb logcat 是否泄露 Token、手机号、密码、内部路径。

4. 网络与后端 API
这是 Android 黑盒的主战场：

代理抓包：Burp / mitmproxy / Charles。

SSL Pinning 绕过：Frida、objection、Xposed，前提是授权。

测 API：

未授权访问、IDOR、水平/垂直越权。

JWT 篡改、过期、无签名、弱密钥。

GraphQL introspection、批量查询、字段越权。

WebSocket、gRPC、WebView 内部请求。

重放、竞态、限流、参数污染。

关注移动端特有 Header：设备 ID、版本、签名、时间戳、nonce。

5. 本地数据存储
SharedPreferences、SQLite、Room、Realm、文件、缓存。

外部存储、SD 卡、下载目录、日志文件。

检查：

Token、密码、身份证、手机号是否明文。

数据库是否加密、能否被其他 App 读取。

adb backup / 自动备份是否可导出敏感数据。

剪贴板、键盘缓存、最近任务截图、通知内容。

6. 组件与 IPC
导出组件：

Activity 越权启动、绕过登录。

Service 绑定、命令执行。

Broadcast Receiver 伪造广播、拦截广播。

Content Provider 查询、SQL 注入、路径遍历。

Intent：

隐式 Intent 劫持、PendingIntent 篡改。

深链 / App Links 参数注入、绕过认证。

工具：drozer、adb、Frida。

7. WebView 与深链
addJavascriptInterface 是否暴露危险方法。

setAllowFileAccess、setJavaScriptEnabled、loadUrl 外部输入。

SSL 错误处理是否忽略证书。

跨域、XSS、本地文件读取、Universal XSS。

深链参数是否进入敏感操作：改密码、支付、跳转。

8. 运行时动态测试（无防护）
Frida / objection：

Hook 登录、加密、签名、风控、Root 检测。

绕过 SSL Pinning、Root 检测、模拟器检测。

导出内存中的密钥、Token。

动态调试：debuggable 时 jdb / IDA / Ghidra。

脱壳：加固 App 先脱壳再分析。

监控文件、网络、进程、Binder 调用。

9. 认证、授权与业务逻辑
本地认证绕过：PIN、密码、生物识别。

Token 存储、刷新、注销、多账号切换。

客户端校验绕过：价格、数量、优惠券、签到、抽奖。

支付逻辑：跳过支付、篡改金额、重放订单。

竞态：并发领券、提现、下单。

服务端是否真正鉴权，不能只靠客户端。

10. 平台与隐私
权限过度申请、动态权限绕过。

截图防护 FLAG_SECURE、Tapjacking、Overlay。

无障碍服务、通知泄露、后台启动。

第三方 SDK：广告、统计、推送、地图、支付。

隐私合规：IMEI、MAC、位置、通讯录、剪贴板。

11. 加固与对抗
混淆、加固、反调试、反 Frida、反 Root。

测试绕过：Frida 改名、端口修改、Hook 检测函数。

脱壳后看真实逻辑。

判断加固是否只是增加成本，而非真正安全。
