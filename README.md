## 仓库约定

- 知识文档使用 Markdown，按主题放在 `docs/` 下。
- 可执行或可复用代码放在 `scripts/` 下。
- 安装包、压缩包等二进制资源放在 `assets/` 下，并记录来源、版本和校验值。
- 文档状态、适用平台和最后验证时间应尽量写在文档开头。
- 原有 Git 提交规范见 [CONTRIBUTING.md](CONTRIBUTING.md)。

## 内容边界

仓库内容用于个人学习、授权测试和设备维护。使用脚本或调试方法前，请确认目标设备、应用和数据属于自己或已获得授权。
