```bash
python3 check_env.py
```

检查内容：

- ✓ Python 版本
- ✓ 内存和磁盘空间
- ✓ 基础工具（git, curl, patch, unzip）
- ✓ 构建工具（meson, ninja, gperf, gcc, make）
- ✓ Vala 编译器（Frida 优化版）
- ✓ Android NDK

### 步骤 2：安装基础依赖

```bash
sudo apt update && sudo apt upgrade -y
sudo apt install -y \
    build-essential \
    meson \
    ninja-build \
    gperf \
    git \
    curl \
    python3 \
    python3-pip \
    libssl-dev \
    zlib1g-dev \
    autoconf \
    automake \
    libtool
```

### 步骤 3：安装 Frida-optimized Vala

```bash
cd /tmp
git clone https://github.com/frida/vala.git
cd vala
git checkout 0.58.0-frida
./autogen.sh --prefix=/usr/local
make -j$(nproc)
sudo make install

echo "/usr/local/lib/x86_64-linux-gnu/vala-0.58" | sudo tee /etc/ld.so.conf.d/vala.conf
sudo ldconfig

valac --version
```

```bash
mkdir -p ~/florida_build/ndk

curl -L "https://dl.google.com/android/repository/android-ndk-r29-linux.zip" -o ndk.zip
unzip -q ndk.zip
export ANDROID_NDK_ROOT=$(pwd)/android-ndk-r29
```

### 步骤 5：克隆 Frida 源码

```bash
cd ~/florida_build
git clone --depth 1 --branch 17.15.3 https://github.com/frida/frida.git
cd frida
git submodule update --init --recursive --depth 1
```

### 步骤 6：下载 Florida 补丁

```bash
cd ~/florida_build
curl -L "https://github.com/Ylarod/Florida/archive/refs/tags/17.15.3.zip" -o florida.zip
unzip -q florida.zip
# 解压后目录: Florida-17.15.3
```

### 步骤 7：应用 Florida 补丁

```bash
# 使用补丁脚本（推荐）
python3 apply_florida_patches.py ~/florida_build/frida ~/florida_build/Florida-17.15.3
```

脚本会自动：
- 按顺序应用所有 frida-core 补丁（10个）
- 按顺序应用所有 frida-gum 补丁（1个）
- 如果 rpc.vala 补丁失败，自动手动修复
- 跳过已应用的补丁（幂等安全）

### 步骤 8：配置构建

```bash
cd ~/florida_build/frida
./configure --host=android-arm64 --without-prebuilds=toolchain
```

> **重要**：configure 会自动下载 minizip-ng 等子项目到 `subprojects/` 目录

### 步骤 9：修复 minizip-ng 兼容性

```bash
# configure 完成后执行
python3 patch_minizip.py ~/florida_build/frida
```

修复内容（自动检测所有 minizip-ng 目录）：
1. **zlib-ng.h 不存在** → 强制使用标准 zlib.h
2. **ftello/fseeko 未声明** → 定义 NO_FSEEKO
3. **SHA 函数缺失** → 添加空实现
4. **MZ_ZIP_NO_CRYPTO 不生效** → 源文件顶部强制定义
5. **meson.build 缺少 Android 配置** → 添加平台检测宏

### 步骤 10：编译

```bash
cd ~/florida_build/frida
ninja -C build -j$(nproc)
```

预计耗时：30-60 分钟（取决于 CPU 性能）

### 步骤 11：验证产物

```bash
# 检查架构
file ~/florida_build/frida/build/subprojects/frida-core/server/frida-server
# 预期输出: ELF 64-bit LSB shared object, ARM aarch64...

# 部署到设备
adb push ~/florida_build/frida/build/subprojects/frida-core/server/frida-server /data/local/tmp/
adb shell chmod 755 /data/local/tmp/frida-server
adb shell /data/local/tmp/frida-server --listen=0.0.0.0:27042 --daemon
```

## 常见问题

### Q1: 环境检查失败怎么办？

根据检查结果的提示信息安装缺失的依赖。常见缺失：
- **gperf**: `sudo apt install gperf`
- **Vala**: 按步骤 3 安装 Frida-optimized Vala
- **NDK**: 按步骤 4 下载 NDK r29

### Q2: 补丁 hunk 失败

`apply_florida_patches.py` 会自动尝试修复 `rpc.vala`。
如果其他补丁失败，可以：
1. 检查 Frida 版本是否完全匹配（必须是 17.15.3）
2. 手动编辑失败的文件，参考补丁文件内容

### Q3: minizip-ng 相关编译错误

确保已执行 `patch_minizip.py`，且在 `configure` **之后**执行。

常见错误及修复：

| 错误信息 | 原因 | 修复 |
|---------|------|------|
| `zlib-ng.h: No such file or directory` | Android NDK 只有标准 zlib | patch_minizip.py 步骤 1 |
| `implicit declaration of function 'ftello'` | bionic libc 缺少该函数 | patch_minizip.py 步骤 2 |
| `undefined symbol: mz_crypt_sha_create` | 禁用加密后缺少实现 | patch_minizip.py 步骤 3 & 4 |

### Q4: Vala 相关错误

```
error: incompatible Vala compiler version
```

原因：使用了系统自带的 Vala，而不是 Frida 优化版。

解决：
```bash
# 确认安装的是 frida 版本
valac --version
which valac

# 如果指向系统路径，调整 PATH
export PATH=/usr/local/bin:$PATH
```

### Q5: ANDROID_NDK_ROOT 未设置

```
./configure: error: ANDROID_NDK_ROOT must be set
```

解决：
```bash
export ANDROID_NDK_ROOT=~/florida_build/ndk/android-ndk-r29
```

### Q6: No C compiler found

确保使用 `--without-prebuilds=toolchain` 参数：
```bash
./configure --host=android-arm64 --without-prebuilds=toolchain
```

#!/usr/bin/env python3
"""
Florida 补丁应用辅助脚本

功能：
1. 自动应用 Florida 补丁
2. 如果补丁失败，手动修复 rpc.vala
3. 验证补丁是否成功应用

用法:
    python3 apply_florida_patches.py <frida_source_dir> <florida_dir>
"""

import os
import sys
import subprocess
import shutil
from pathlib import Path


def run_patch(target_dir: Path, patch_file: Path) -> tuple:
    """应用一个补丁文件，返回 (success, message)"""
    cmd = ['patch', '-p1', '-N', '-d', str(target_dir), '-i', str(patch_file)]
    try:
        result = subprocess.run(
            cmd, capture_output=True, text=True, timeout=30
        )
        success = result.returncode == 0
        return success, result.stdout + result.stderr
    except Exception as e:
        return False, str(e)


def apply_patches_in_order(patch_dir: Path, target_dir: Path, label: str) -> int:
    """按顺序应用目录中的所有补丁"""
    if not patch_dir.exists():
        print(f"  [警告] 补丁目录不存在: {patch_dir}")
        return 0
    
    patches = sorted(patch_dir.glob('*.patch'))
    if not patches:
        print(f"  [警告] 未找到补丁文件: {patch_dir}")
        return 0
    
    print(f"\n应用 {label} 补丁 ({len(patches)} 个):")
    success_count = 0
    
    for patch_file in patches:
        ok, output = run_patch(target_dir, patch_file)
        name = patch_file.name
        
        if ok:
            if 'Reversed (or previously applied) patch detected' in output:
                print(f"  ✓ {name} (已应用，跳过)")
            else:
                print(f"  ✓ {name}")
            success_count += 1
        else:
            if 'Reversed (or previously applied) patch detected' in output:
                print(f"  ✓ {name} (已应用，跳过)")
                success_count += 1
            elif 'FAILED' in output or 'hunk' in output.lower():
                print(f"  ✗ {name} (hunk 失败，需要手动修复)")
                # 显示失败的 hunk 信息
                for line in output.split('\n'):
                    if 'FAILED' in line or 'hunk' in line.lower():
                        print(f"    {line.strip()}")
            else:
                print(f"  ✗ {name} (失败)")
                print(f"    {output[:200]}")
    
    return success_count


def check_rpc_vala_patched(frida_core_dir: Path) -> bool:
    """检查 rpc.vala 是否已包含 getRpcStr 函数"""
    rpc_vala = frida_core_dir / 'lib' / 'base' / 'rpc.vala'
    if not rpc_vala.exists():
        return False
    
    content = rpc_vala.read_text(errors='ignore')
    return 'getRpcStr' in content


def fix_rpc_vala_manually(frida_core_dir: Path) -> bool:
    """手动修复 rpc.vala，添加 getRpcStr 函数"""
    rpc_vala = frida_core_dir / 'lib' / 'base' / 'rpc.vala'
    if not rpc_vala.exists():
        print(f"  [错误] 文件不存在: {rpc_vala}")
        return False
    
    if check_rpc_vala_patched(frida_core_dir):
        print(f"  [跳过] rpc.vala 已修复")
        return True
    
    # 备份
    backup = rpc_vala.with_suffix(rpc_vala.suffix + '.bak')
    if not backup.exists():
        shutil.copy2(rpc_vala, backup)
    
    content = rpc_vala.read_text()
    
    # getRpcStr 函数
    getrpcstr_func = '''
		public string getRpcStr(bool quote){
			string result = (string) GLib.Base64.decode((string) GLib.Base64.decode("Wm5KcFpHRTZjbkJq"));
			if(quote){
				return "\\"" + result + "\\"";
			}else{
				return result;
			}
		}
'''
    
    # 找到 RpcClient 类中插入函数的位置
    # 在 public RpcClient (RpcPeer peer) 构造函数之后插入
    import re
    
    # 方式1：在构造函数之后插入
    pattern = r'(public RpcClient \(RpcPeer peer\) \{\s*Object \(peer: peer\);\s*\})'
    match = re.search(pattern, content)
    
    if match:
        insert_pos = match.end()
        new_content = content[:insert_pos] + '\n' + getrpcstr_func + content[insert_pos:]
        content = new_content
    else:
        print(f"  [错误] 找不到构造函数插入点")
        return False
    
    # 替换第一个 .add_string_value ("frida") 为 .add_string_value (getRpcStr(false))
    # 替换第一个字符串 "frida" 为 getRpcStr(false)
    # 在 call 方法中
    call_pattern = r'(\.add_string_value \()("frida")(\)'
    if re.search(call_pattern, content):
        content = re.sub(call_pattern, r'\1getRpcStr(false)\3', content, count=1)
    else:
        # 尝试其他模式
        content = content.replace('.add_string_value ("frida")', '.add_string_value (getRpcStr(false))', 1)
    
    # 替换其他 frida 字符串引用
    # 在 json.index_of 中
    content = content.replace('json.index_of ("frida")', 'json.index_of (getRpcStr(true))')
    content = content.replace("json.index_of ('\"frida\"')", 'json.index_of (getRpcStr(true))')
    
    # 在 type 判断中
    type_pattern = r'(type\s*==\s*null\s*\|\|\s*type\s*!=\s*)("frida")'
    if re.search(type_pattern, content):
        content = re.sub(type_pattern, r'\1getRpcStr(false)', content)
    else:
        content = content.replace('type != "frida"', 'type != getRpcStr(false)')
    
    rpc_vala.write_text(content)
    print(f"  [修复] rpc.vala (手动添加 getRpcStr)")
    return True


def main():
    if len(sys.argv) < 3:
        print("用法: python3 apply_florida_patches.py <frida_source_dir> <florida_dir>")
        print("示例: python3 apply_florida_patches.py ~/florida_build/frida ~/florida_build/Florida-17.15.3")
        sys.exit(1)
    
    frida_root = Path(sys.argv[1]).expanduser().resolve()
    florida_dir = Path(sys.argv[2]).expanduser().resolve()
    
    if not frida_root.exists():
        print(f"错误: Frida 目录不存在: {frida_root}")
        sys.exit(1)
    
    if not florida_dir.exists():
        print(f"错误: Florida 目录不存在: {florida_dir}")
        sys.exit(1)
    
    print("=" * 60)
    print("应用 Florida 补丁")
    print(f"Frida 源码: {frida_root}")
    print(f"Florida 补丁: {florida_dir}")
    print("=" * 60)
    
    frida_core_dir = frida_root / 'subprojects' / 'frida-core'
    frida_gum_dir = frida_root / 'subprojects' / 'frida-gum'
    
    # 应用 frida-core 补丁
    core_patch_dir = florida_dir / 'patches' / 'frida-core'
    core_success = apply_patches_in_order(core_patch_dir, frida_core_dir, "frida-core")
    
    # 应用 frida-gum 补丁
    gum_patch_dir = florida_dir / 'patches' / 'frida-gum'
    gum_success = apply_patches_in_order(gum_patch_dir, frida_gum_dir, "frida-gum")
    
    # 检查并手动修复 rpc.vala
    print("\n检查 rpc.vala:")
    if not check_rpc_vala_patched(frida_core_dir):
        print("  检测到补丁未完全应用，尝试手动修复...")
        fix_rpc_vala_manually(frida_core_dir)
    else:
        print("  ✓ 已包含 getRpcStr 函数")
    
    # 最终验证
    print("\n" + "=" * 60)
    print("补丁应用完成")
    print("=" * 60)
    print(f"frida-core: {core_success} 个补丁")
    print(f"frida-gum: {gum_success} 个补丁")
    
    if check_rpc_vala_patched(frida_core_dir):
        print("rpc.vala: ✓ 已修复")
    else:
        print("rpc.vala: ✗ 未修复（需要手动处理）")


if __name__ == '__main__':
    main()

#!/usr/bin/env python3
"""
Frida Florida 构建环境检查脚本

检查内容：
- 系统架构和操作系统
- 必要的系统依赖（git, curl, python3, meson, ninja, gperf 等）
- 磁盘空间
- 内存大小
- Python 版本
- Android NDK
- Vala 编译器

用法:
    python3 check_env.py [--ndk-path <path>]
"""

import os
import sys
import shutil
import subprocess
from pathlib import Path
from typing import Tuple, List


class CheckResult:
    def __init__(self, name: str, passed: bool, message: str, fix_hint: str = None):
        self.name = name
        self.passed = passed
        self.message = message
        self.fix_hint = fix_hint


def run_cmd(cmd: list) -> Tuple[int, str, str]:
    """执行命令并返回 (returncode, stdout, stderr)"""
    try:
        result = subprocess.run(
            cmd, capture_output=True, text=True, timeout=10
        )
        return result.returncode, result.stdout.strip(), result.stderr.strip()
    except Exception as e:
        return -1, "", str(e)


def check_os() -> CheckResult:
    """检查操作系统"""
    import platform
    system = platform.system()
    machine = platform.machine()
    
    if system != 'Linux':
        return CheckResult(
            "操作系统", False,
            f"当前系统: {system}",
            "本脚本仅支持 Linux 系统"
        )
    
    if machine != 'x86_64':
        return CheckResult(
            "系统架构", False,
            f"当前架构: {machine}",
            "Frida Android 交叉编译需要 x86_64 架构"
        )
    
    return CheckResult(
        "操作系统", True,
        f"Linux ({machine})"
    )


def check_python() -> CheckResult:
    """检查 Python 版本"""
    version = sys.version_info
    if version.major < 3 or (version.major == 3 and version.minor < 8):
        return CheckResult(
            "Python 版本", False,
            f"当前版本: {version.major}.{version.minor}.{version.micro}",
            "需要 Python 3.8 或更高版本"
        )
    return CheckResult(
        "Python 版本", True,
        f"{version.major}.{version.minor}.{version.micro}"
    )


def check_command(cmd: str, name: str = None, min_version: str = None,
                  version_flag: str = '--version') -> CheckResult:
    """检查命令是否存在"""
    name = name or cmd
    path = shutil.which(cmd)
    
    if not path:
        return CheckResult(
            name, False,
            "未安装",
            f"请安装: {cmd}"
        )
    
    # 检查版本
    if min_version:
        ret, out, _ = run_cmd([cmd, version_flag])
        if ret == 0 and out:
            # 提取版本号
            import re
            match = re.search(r'(\d+\.\d+[\.\d]*)', out)
            if match:
                version = match.group(1)
                return CheckResult(
                    name, True,
                    f"{version} ({path})"
                )
    
    return CheckResult(
        name, True,
        f"已安装 ({path})"
    )


def check_disk_space(path: str = '.', min_gb: int = 20) -> CheckResult:
    """检查磁盘空间"""
    try:
        stat = shutil.disk_usage(path)
        free_gb = stat.free / (1024**3)
        
        if free_gb < min_gb:
            return CheckResult(
                "磁盘空间", False,
                f"剩余: {free_gb:.1f} GB",
                f"至少需要 {min_gb} GB 可用空间"
            )
        
        return CheckResult(
            "磁盘空间", True,
            f"剩余: {free_gb:.1f} GB"
        )
    except Exception as e:
        return CheckResult(
            "磁盘空间", False,
            f"检查失败: {e}",
            None
        )


def check_memory(min_gb: int = 4) -> CheckResult:
    """检查内存大小"""
    try:
        with open('/proc/meminfo', 'r') as f:
            for line in f:
                if line.startswith('MemTotal:'):
                    parts = line.split()
                    total_kb = int(parts[1])
                    total_gb = total_kb / (1024 * 1024)
                    
                    if total_gb < min_gb:
                        return CheckResult(
                            "内存大小", False,
                            f"{total_gb:.1f} GB",
                            f"建议至少 {min_gb} GB 内存（8GB 更佳）"
                        )
                    
                    return CheckResult(
                        "内存大小", True,
                        f"{total_gb:.1f} GB"
                    )
    except Exception:
        pass
    
    return CheckResult(
        "内存大小", True,
        "无法检测（假设满足要求）"
    )


def check_ndk(ndk_path: str = None) -> CheckResult:
    """检查 Android NDK"""
    # 尝试从环境变量获取
    if not ndk_path:
        ndk_path = os.environ.get('ANDROID_NDK_ROOT', '')
    
    if not ndk_path:
        return CheckResult(
            "Android NDK", False,
            "未设置 ANDROID_NDK_ROOT",
            "请下载 Android NDK r29 并设置 ANDROID_NDK_ROOT"
        )
    
    ndk_dir = Path(ndk_path).expanduser()
    
    if not ndk_dir.exists():
        return CheckResult(
            "Android NDK", False,
            f"路径不存在: {ndk_path}",
            "请确认 NDK 路径是否正确"
        )
    
    # 检查是否有 toolchain
    toolchain = ndk_dir / 'toolchains' / 'llvm' / 'prebuilt' / 'linux-x86_64' / 'bin'
    if toolchain.exists():
        return CheckResult(
            "Android NDK", True,
            f"已安装 ({ndk_dir.name})"
        )
    
    return CheckResult(
        "Android NDK", True,
        f"已安装 (路径: {ndk_dir.name})"
    )


def check_vala() -> CheckResult:
    """检查 Vala 编译器"""
    valac = shutil.which('valac')
    
    if not valac:
        return CheckResult(
            "Vala 编译器", False,
            "未安装",
            "需要安装 Frida-optimized Vala (0.58.0-frida)"
        )
    
    ret, out, _ = run_cmd([valac, '--version'])
    if ret == 0 and out:
        if 'frida' in out.lower() or '0.58' in out:
            return CheckResult(
                "Vala 编译器", True,
                out
            )
        return CheckResult(
            "Vala 编译器", False,
            out,
            "需要 Frida-optimized Vala 0.58.x，系统自带版本不兼容"
        )
    
    return CheckResult(
        "Vala 编译器", True,
        "已安装"
    )

#!/usr/bin/env python3
"""
minizip-ng Android 兼容性修复脚本

修复以下问题：
1. zlib-ng.h 不存在 -> 强制使用标准 zlib.h
2. ftello/fseeko 未声明 -> 定义 NO_FSEEKO
3. MZ_ZIP_NO_CRYPTO 模式下缺少 SHA 函数 -> 添加空实现
4. config.h 宏传递问题 -> 在源文件中强制定义

用法:
    python3 patch_minizip.py <frida_source_dir>

示例:
    python3 patch_minizip.py ~/florida_build/frida
"""

import os
import sys
import shutil
from pathlib import Path


def backup_file(filepath: Path) -> Path:
    """创建文件备份，返回备份路径"""
    backup = filepath.with_suffix(filepath.suffix + '.bak')
    if not backup.exists():
        shutil.copy2(filepath, backup)
    return backup


def file_contains(filepath: Path, text: str) -> bool:
    """检查文件是否包含指定文本"""
    if not filepath.exists():
        return False
    content = filepath.read_text(errors='ignore')
    return text in content


def patch_mz_strm_zlib(filepath: Path) -> bool:
    """
    修复 mz_strm_zlib.c：强制使用标准 zlib 而不是 zlib-ng
    
    问题: Android NDK 只有标准 zlib.h，没有 zlib-ng.h
    方案: 在文件顶部定义 ZLIB_COMPAT，保留原有条件编译但保证兼容模式
    """
    if not filepath.exists():
        print(f"  [跳过] 文件不存在: {filepath}")
        return False
    
    if file_contains(filepath, '/* PATCHED: ZLIB_COMPAT */'):
        print(f"  [跳过] 已修复: {filepath.name}")
        return True
    
    backup_file(filepath)
    content = filepath.read_text()
    
    marker = '/* PATCHED: ZLIB_COMPAT */'
    patch_code = f'''{marker}
#define ZLIB_COMPAT
#include "zlib.h"
/* END PATCHED */

'''
    
    # 在第一个 #include 之前插入补丁
    first_include = content.find('#include')
    if first_include == -1:
        print(f"  [错误] 找不到 #include: {filepath.name}")
        return False
    
    # 移除原有的 zlib-ng/zlib 条件编译块
    import re
    content = re.sub(
        r'#if\s+!defined\(ZLIB_COMPAT\)\s*\n\s*#\s*include\s*"zlib-ng\.h"\s*\n#else\s*\n\s*#\s*include\s*"zlib\.h"\s*\n#endif\s*\n',
        '',
        content
    )
    
    # 重新插入
    first_include = content.find('#include')
    new_content = content[:first_include] + patch_code + content[first_include:]
    
    filepath.write_text(new_content)
    print(f"  [修复] {filepath.name}")
    return True


def patch_mz_strm_os_posix(filepath: Path) -> bool:
    """
    修复 mz_strm_os_posix.c：定义 NO_FSEEKO
    
    问题: Android bionic libc 缺少 ftello/fseeko 函数
    方案: 在 stdio.h 之前定义 NO_FSEEKO
    """
    if not filepath.exists():
        print(f"  [跳过] 文件不存在: {filepath}")
        return False
    
    if file_contains(filepath, '/* PATCHED: NO_FSEEKO */'):
        print(f"  [跳过] 已修复: {filepath.name}")
        return True
    
    backup_file(filepath)
    content = filepath.read_text()
    
    marker = '/* PATCHED: NO_FSEEKO */'
    patch_code = f'{marker}\n#define NO_FSEEKO\n/* END PATCHED */\n\n'
    
    # 在 #include <stdio.h> 之前插入
    stdio_pos = content.find('#include <stdio.h>')
    if stdio_pos == -1:
        print(f"  [错误] 找不到 #include <stdio.h>: {filepath.name}")
        return False
    
    new_content = content[:stdio_pos] + patch_code + content[stdio_pos:]
    
    filepath.write_text(new_content)
    print(f"  [修复] {filepath.name}")
    return True


def patch_mz_crypt(filepath: Path) -> bool:
    """
    修复 mz_crypt.c：添加 SHA 函数空实现
    
    问题: MZ_ZIP_NO_CRYPTO 模式下 mz_zip_rw.c 仍然调用 SHA 函数
    方案: 在 MZ_ZIP_NO_CRYPTO 条件块中添加空实现
    """
    if not filepath.exists():
        print(f"  [跳过] 文件不存在: {filepath}")
        return False
    
    if file_contains(filepath, '/* PATCHED: SHA stubs */'):
        print(f"  [跳过] 已修复: {filepath.name}")
        return True
    
    backup_file(filepath)
    content = filepath.read_text()
    
    # 找到 MZ_ZIP_NO_CRYPTO 块中的 mz_crypt_rand 函数
    import re
    
    sha_stubs = '''
/* PATCHED: SHA stubs */
void *mz_crypt_sha_create(void **handle) { return NULL; }
void mz_crypt_sha_set_algorithm(void *handle, uint16_t algorithm) { (void)handle; (void)algorithm; }
int32_t mz_crypt_sha_begin(void *handle) { (void)handle; return 0; }
int32_t mz_crypt_sha_update(void *handle, const void *buf, int32_t size) { (void)handle; (void)buf; (void)size; return 0; }
int32_t mz_crypt_sha_end(void *handle, uint8_t *digest, int32_t digest_size) { (void)handle; (void)digest; (void)digest_size; return 0; }
void mz_crypt_sha_delete(void **handle) { (void)handle; }
void mz_crypt_sha_reset(void *handle) { (void)handle; }
/* END PATCHED */
'''
    
    # 在 mz_crypt_rand 函数结束后插入
    pattern = r'(int32_t\s+mz_crypt_rand\s*\([^)]*\)\s*\{[^}]*return mz_os_rand\([^)]*\);\s*\})'
    match = re.search(pattern, content)
    if match:
        insert_pos = match.end()
        new_content = content[:insert_pos] + '\n' + sha_stubs + content[insert_pos:]
        filepath.write_text(new_content)
        print(f"  [修复] {filepath.name}")
        return True
    else:
        # 备用方案：在 #endif /* MZ_ZIP_NO_CRYPTO */ 之前插入
        endif_pattern = r'(#\s*if\s+defined\(MZ_ZIP_NO_CRYPTO\)[\s\S]*?)(#\s*endif)'
        match = re.search(endif_pattern, content)
        if match:
            insert_pos = match.start(2)
            new_content = content[:insert_pos] + sha_stubs + '\n' + content[insert_pos:]
            filepath.write_text(new_content)
            print(f"  [修复] {filepath.name} (备用方案)")
            return True
    
    print(f"  [错误] 无法定位插入点: {filepath.name}")
    return False


def patch_mz_zip_rw(filepath: Path) -> bool:
    """
    修复 mz_zip_rw.c：强制定义 MZ_ZIP_NO_CRYPTO
    
    问题: config.h 中的宏定义可能未正确传递到所有编译单元
    方案: 在源文件顶部强制定义
    """
    if not filepath.exists():
        print(f"  [跳过] 文件不存在: {filepath}")
        return False
    
    if file_contains(filepath, '/* PATCHED: MZ_ZIP_NO_CRYPTO */'):
        print(f"  [跳过] 已修复: {filepath.name}")
        return True
    
    backup_file(filepath)
    content = filepath.read_text()
    
    marker = '/* PATCHED: MZ_ZIP_NO_CRYPTO */'
    patch_code = f'{marker}\n#define MZ_ZIP_NO_CRYPTO\n#define MZ_ZIP_NO_ENCRYPTION\n/* END PATCHED */\n\n'
    
    # 在第一个 #include 之前插入
    first_include = content.find('#include')
    if first_include == -1:
        print(f"  [错误] 找不到 #include: {filepath.name}")
        return False
    
    new_content = content[:first_include] + patch_code + content[first_include:]
    
    filepath.write_text(new_content)
    print(f"  [修复] {filepath.name}")
    return True


def patch_meson_build(filepath: Path) -> bool:
    """
    修复 meson.build：添加 Android 平台检测和必要宏定义
    
    问题: minizip-ng 默认针对 Linux 桌面，缺少 Android 特定配置
    """
    if not filepath.exists():
        print(f"  [跳过] 文件不存在: {filepath}")
        return False
    
    if file_contains(filepath, '# PATCHED: Android support'):
        print(f"  [跳过] 已修复: {filepath.name}")
        return True
    
    backup_file(filepath)
    content = filepath.read_text()
    
    import re
    
    # 替换原有的 NO_FSEEKO 定义
    old_pattern = r"cdata\.set\('NO_FSEEKO', not cc\.has_function\('fseeko', prefix: '#include <stdio\.h>'\)\)"
    
    android_patch = '''# PATCHED: Android support
if host_machine.system() == 'android'
  cdata.set('NO_FSEEKO', true)
else
  cdata.set('NO_FSEEKO', not cc.has_function('fseeko', prefix: '#include <stdio.h>'))
endif

cdata.set('_POSIX_C_SOURCE', '200112L')
cdata.set('_LARGEFILE_SOURCE', true)
cdata.set('_FILE_OFFSET_BITS', 64)
# END PATCHED'''
    
    if re.search(old_pattern, content):
        new_content = re.sub(old_pattern, android_patch, content)
        filepath.write_text(new_content)
        print(f"  [修复] {filepath.name}")
        return True
    else:
        # 备用：在 zlib_dep 检查之前插入
        zlib_pos = content.find("zlib_dep = dependency('zlib'")
        if zlib_pos != -1:
            new_content = content[:zlib_pos] + '\n' + android_patch + '\n\n' + content[zlib_pos:]
            filepath.write_text(new_content)
            print(f"  [修复] {filepath.name} (备用方案)")
            return True
    
    print(f"  [错误] 无法定位插入点: {filepath.name}")
    return False


def patch_minizip_dir(minizip_dir: Path, label: str) -> bool:
    """修复一个 minizip-ng 目录中的所有文件"""
    print(f"\n修复 {label}: {minizip_dir}")
    
    if not minizip_dir.exists():
        print(f"  [警告] 目录不存在，跳过")
        return False
    
    results = []
    
    # 修复各个文件
    results.append(patch_mz_strm_zlib(minizip_dir / 'mz_strm_zlib.c'))
    results.append(patch_mz_strm_os_posix(minizip_dir / 'mz_strm_os_posix.c'))
    results.append(patch_mz_crypt(minizip_dir / 'mz_crypt.c'))
    results.append(patch_mz_zip_rw(minizip_dir / 'mz_zip_rw.c'))
    results.append(patch_meson_build(minizip_dir / 'meson.build'))
    
    success = sum(1 for r in results if r)
    total = len(results)
    print(f"  结果: {success}/{total} 项修复成功")
    
    return success > 0


def find_minizip_dirs(frida_root: Path):
    """查找所有 minizip-ng 目录"""
    dirs = []
    
    # 主项目
    main_dir = frida_root / 'subprojects' / 'minizip-ng'
    if main_dir.exists():
        dirs.append((main_dir, '主项目'))
    
    # frida-core
    core_dir = frida_root / 'subprojects' / 'frida-core' / 'subprojects' / 'minizip-ng'
    if core_dir.exists():
        dirs.append((core_dir, 'frida-core'))
    
    # frida-gum
    gum_dir = frida_root / 'subprojects' / 'frida-gum' / 'subprojects' / 'minizip-ng'
    if gum_dir.exists():
        dirs.append((gum_dir, 'frida-gum'))
    
    # frida-core 中的 frida-gum
    core_gum_dir = frida_root / 'subprojects' / 'frida-core' / 'subprojects' / 'frida-gum' / 'subprojects' / 'minizip-ng'
    if core_gum_dir.exists() and core_gum_dir != gum_dir:
        dirs.append((core_gum_dir, 'frida-core/frida-gum'))
    
    return dirs


def main():
    if len(sys.argv) < 2:
        print("用法: python3 patch_minizip.py <frida_source_dir>")

    for d, label in minizip_dirs:

    total_success = 0
    for minizip_dir, label in minizip_dirs:

    print("\n" + "=" * 60)
    print(f"修复完成: {total_success}/{len(minizip_dirs)} 个目录")
    print("=" * 60)
    
    if total_success == 0:
        sys.exit(1)


if __name__ == '__main__':
    main()

FLORIDA_VERSION="17.15.3"
NDK_VERSION="r29"
BUILD_DIR="${BUILD_DIR:-$HOME/florida_build}"
NUM_JOBS="${NUM_JOBS:-$(nproc)}"

# 颜色输出
RED='\033[0;31m'
GREEN='\033[0;32m'
YELLOW='\033[1;33m'
BLUE='\033[0;34m'
NC='\033[0m' # No Color

# =============================================================================
# 日志函数
# =============================================================================

log_info() {
    echo -e "${BLUE}[INFO]${NC} $1"
}

log_success() {
    echo -e "${GREEN}[SUCCESS]${NC} $1"
}

log_warn() {
    echo -e "${YELLOW}[WARN]${NC} $1"
}

log_error() {
    echo -e "${RED}[ERROR]${NC} $1" >&2
}

print_banner() {
    echo ""
    echo "============================================================================="
    echo "$1"
    echo "============================================================================="
}

# =============================================================================
# 检查函数
# =============================================================================

check_command() {
    if ! command -v "$1" &> /dev/null; then
        return 1
    fi
    return 0
}

require_command() {
    if ! check_command "$1"; then
        log_error "缺少必要命令: $1"
        log_error "请先安装: $2"
        exit 1
    fi
}

# =============================================================================
# 步骤函数
# =============================================================================

step_01_check_env() {
    print_banner "步骤 1/8: 环境检查"
    
    local script_dir="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
    local check_script="$script_dir/check_env.py"
    
    if [ -f "$check_script" ]; then
        python3 "$check_script" --build-dir "$BUILD_DIR" --ndk-path "${ANDROID_NDK_ROOT:-}" || {
            log_error "环境检查未通过，请先解决上述问题"
            exit 1
        }
    else
        log_warn "未找到环境检查脚本，跳过自动检查"
    fi
    
    # 基础命令检查
    require_command "git" "git"
    require_command "curl" "curl"
    require_command "python3" "python3"
    
    log_success "环境检查完成"
}

step_02_prepare_dirs() {
    print_banner "步骤 2/8: 准备目录"
    
    mkdir -p "$BUILD_DIR"
    mkdir -p "$BUILD_DIR/ndk"
    
    log_success "目录已创建: $BUILD_DIR"
}

step_03_download_ndk() {
    print_banner "步骤 3/8: 下载 Android NDK"
    
    local ndk_dir="$BUILD_DIR/ndk/android-ndk-$NDK_VERSION"
    
    if [ -d "$ndk_dir" ]; then
        log_success "NDK 已存在，跳过下载: $ndk_dir"
        export ANDROID_NDK_ROOT="$ndk_dir"
        return 0
    fi
    
    log_info "下载 Android NDK $NDK_VERSION..."
    local ndk_zip="$BUILD_DIR/ndk/android-ndk-${NDK_VERSION}-linux.zip"
    
    if [ ! -f "$ndk_zip" ]; then
        curl -L "https://dl.google.com/android/repository/android-ndk-${NDK_VERSION}-linux.zip" -o "$ndk_zip"
    fi
    
    log_info "解压 NDK..."
    unzip -q "$ndk_zip" -d "$BUILD_DIR/ndk/"
    
    export ANDROID_NDK_ROOT="$ndk_dir"
    log_success "NDK 安装完成: $ndk_dir"
}

step_04_clone_frida() {
    print_banner "步骤 4/8: 克隆 Frida 源码"
    
    local frida_dir="$BUILD_DIR/frida"
    
    if [ -d "$frida_dir" ]; then
        log_success "Frida 源码已存在，跳过克隆"
        cd "$frida_dir"
        return 0
    fi
    
    log_info "克隆 Frida $FRIDA_VERSION..."
    cd "$BUILD_DIR"
    git clone --depth 1 --branch "$FRIDA_VERSION" https://github.com/frida/frida.git
    
    cd frida
    
    log_info "更新子模块 (需要较长时间)..."
    git submodule update --init --recursive --depth 1
    
    log_success "Frida 源码准备完成"
}

step_05_download_florida() {
    print_banner "步骤 5/8: 下载 Florida 补丁"
    
    local florida_dir="$BUILD_DIR/Florida-$FLORIDA_VERSION"
    local florida_zip="$BUILD_DIR/florida-${FLORIDA_VERSION}.zip"
    
    if [ -d "$florida_dir" ]; then
        log_success "Florida 补丁已存在，跳过下载"
        return 0
    fi
    
    log_info "下载 Florida $FLORIDA_VERSION..."
    curl -L "https://github.com/Ylarod/Florida/archive/refs/tags/${FLORIDA_VERSION}.zip" -o "$florida_zip"
    
    log_info "解压 Florida..."
    unzip -q "$florida_zip" -d "$BUILD_DIR/"
    
    log_success "Florida 补丁准备完成: $florida_dir"
}

step_06_apply_patches() {
    print_banner "步骤 6/8: 应用 Florida 补丁"
    
    local frida_dir="$BUILD_DIR/frida"
    local florida_dir="$BUILD_DIR/Florida-$FLORIDA_VERSION"
    local script_dir="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
    local patch_script="$script_dir/apply_florida_patches.py"
    
    if [ -f "$patch_script" ]; then
        python3 "$patch_script" "$frida_dir" "$florida_dir"
    else
        log_warn "未找到补丁脚本，使用手动方式应用..."
        
        # 应用 frida-core 补丁
        cd "$frida_dir/subprojects/frida-core"
        for patch in "$florida_dir/patches/frida-core/"*.patch; do
            log_info "应用: $(basename "$patch")"
            patch -p1 -N < "$patch" || true
        done
        
        # 应用 frida-gum 补丁
        cd "$frida_dir/subprojects/frida-gum"
        for patch in "$florida_dir/patches/frida-gum/"*.patch; do
            log_info "应用: $(basename "$patch")"
            patch -p1 -N < "$patch" || true
        done
    fi
    
    log_success "补丁应用完成"
}

step_07_configure_build() {
    print_banner "步骤 7/8: 配置构建"
    
    local frida_dir="$BUILD_DIR/frida"
    local script_dir="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
    local patch_script="$script_dir/patch_minizip.py"
    
    cd "$frida_dir"
    
    # 清理旧构建
    if [ -d "build" ]; then
        log_warn "检测到旧构建目录，是否清理？(y/N)"
        read -r answer
        if [[ "$answer" =~ ^[Yy]$ ]]; then
            rm -rf build
            log_info "已清理旧构建目录"
        fi
    fi
    
    # 配置
    log_info "运行 configure..."
    ./configure --host=android-arm64 --without-prebuilds=toolchain
    
    # 配置完成后修复 minizip-ng
    # 因为 minizip-ng 是 meson 在 configure 阶段下载的
    log_info "修复 minizip-ng Android 兼容性..."
    
    if [ -f "$patch_script" ]; then
        python3 "$patch_script" "$frida_dir"
    else
        log_error "未找到 minizip 补丁脚本: $patch_script"
        exit 1
    fi
    
    log_success "构建配置完成"
}

step_08_build() {
    print_banner "步骤 8/8: 编译"
    
    local frida_dir="$BUILD_DIR/frida"
    cd "$frida_dir"
    
    log_info "开始编译 (使用 $NUM_JOBS 个线程)..."
    log_info "这可能需要 30-60 分钟，请耐心等待..."
    
    ninja -C build -j"$NUM_JOBS"
    
    # 验证产物
    local server_path="build/subprojects/frida-core/server/frida-server"
    
    if [ -f "$server_path" ]; then
        log_success "构建成功！"
        echo ""
        echo "构建产物位置："
        echo "  - frida-server:     $BUILD_DIR/frida/$server_path"
        echo "  - frida-agent.so:   $BUILD_DIR/frida/build/subprojects/frida-core/lib/agent/frida-agent.so"
        echo "  - frida-gadget.so:  $BUILD_DIR/frida/build/subprojects/frida-core/lib/gadget/frida-gadget.so"
        echo ""
        echo "部署到设备："
        echo "  adb push $BUILD_DIR/frida/$server_path /data/local/tmp/"
        echo "  adb shell chmod 755 /data/local/tmp/frida-server"
        echo "  adb shell /data/local/tmp/frida-server --listen=0.0.0.0:27042 --daemon"
    else
        log_error "未找到 frida-server，构建可能失败"
        exit 1
    fi
}

# =============================================================================
# 主函数
# =============================================================================

show_help() {
    cat << EOF
Frida Florida Android arm64 一键构建脚本 v2.0

用法:
    $0 [选项]

选项:
    -h, --help          显示帮助
    --skip-env-check    跳过环境检查
    --skip-ndk          跳过 NDK 下载
    --skip-frida        跳过 Frida 源码克隆
    --skip-florida      跳过 Florida 下载
    --skip-patches      跳过补丁应用
    --skip-configure    跳过配置步骤
    --build-only        仅执行编译步骤（需先完成配置）
    --clean             清理构建目录后重新开始

环境变量:
    BUILD_DIR           构建目录 (默认: ~/florida_build)
    NUM_JOBS            编译线程数 (默认: nproc)
    ANDROID_NDK_ROOT    NDK 路径 (自动下载时无需设置)

示例:
    # 完整构建
    $0
    
    # 仅编译（已完成配置）
    $0 --build-only
    
    # 清理并重新构建
    $0 --clean
EOF
}

main() {
    local skip_env_check=false
    local skip_ndk=false
    local skip_frida=false
    local skip_florida=false
    local skip_patches=false
    local skip_configure=false
    local build_only=false
    local clean=false
    
    # 解析参数
    while [[ $# -gt 0 ]]; do
        case "$1" in
            -h|--help)
                show_help
                exit 0
                ;;
            --skip-env-check)
                skip_env_check=true
                shift
                ;;
            --skip-ndk)
                skip_ndk=true
                shift
                ;;
            --skip-frida)
                skip_frida=true
                shift
                ;;
            --skip-florida)
                skip_florida=true
                shift
                ;;
            --skip-patches)
                skip_patches=true
                shift
                ;;
            --skip-configure)
                skip_configure=true
                shift
                ;;
            --build-only)
                skip_env_check=true
                skip_ndk=true
                skip_frida=true
                skip_florida=true
                skip_patches=true
                skip_configure=true
                shift
                ;;
            --clean)
                clean=true
                shift
                ;;
            *)
                log_error "未知选项: $1"
                show_help
                exit 1
                ;;
        esac
    done
    
    # 清理构建
    if [ "$clean" = true ]; then
        log_warn "将清理构建目录: $BUILD_DIR/frida/build"
        rm -rf "$BUILD_DIR/frida/build"
        log_success "已清理构建目录"
    fi
    
    # 记录开始时间
    local start_time=$(date +%s)
    
    echo ""
    echo "============================================================================="
    echo "  Frida Florida Android arm64 构建脚本 v2.0"
    echo "  Frida 版本: $FRIDA_VERSION"
    echo "  Florida 版本: $FLORIDA_VERSION"
    echo "  NDK 版本: $NDK_VERSION"
    echo "  构建目录: $BUILD_DIR"
    echo "============================================================================="
    
    # 执行各步骤
    if [ "$skip_env_check" = false ]; then
        step_01_check_env
    fi
    
    step_02_prepare_dirs
    
    if [ "$skip_ndk" = false ]; then
        step_03_download_ndk
    else
        # 确保 NDK 路径已设置
        if [ -z "${ANDROID_NDK_ROOT:-}" ]; then
            export ANDROID_NDK_ROOT="$BUILD_DIR/ndk/android-ndk-$NDK_VERSION"
        fi
        log_info "使用 NDK: $ANDROID_NDK_ROOT"
    fi
    
    if [ "$skip_frida" = false ]; then
        step_04_clone_frida
    fi
    
    if [ "$skip_florida" = false ]; then
        step_05_download_florida
    fi
    
    if [ "$skip_patches" = false ]; then
        step_06_apply_patches
    fi
    
    if [ "$skip_configure" = false ]; then
        step_07_configure_build
    fi
    
    step_08_build
    
    # 统计耗时
    local end_time=$(date +%s)
    local duration=$((end_time - start_time))
    local hours=$((duration / 3600))
    local minutes=$(( (duration % 3600) / 60 ))
    local seconds=$((duration % 60))
    
    echo ""
    echo "============================================================================="
    log_success "全部完成！总耗时: ${hours}h ${minutes}m ${seconds}s"
    echo "============================================================================="
}

# 执行主函数
main "$@"
